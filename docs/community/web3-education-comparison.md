## Key Differentiators

### Get-Started-with-Web3
- **Bilingual (EN + ZH)**: Few projects serve both audiences well
- **Structured 7-course curriculum**: Wallet → Contract → DeFi → NFT → Security → DAO → ZKP
- **Community-driven**: Open issues, WeChat group, active maintainer
- **Gap**: Lacks interactive coding environment (uses external links)

### LearnWeb3 DAO
- **Four-tier system**: Freshman (basics) → Sophomore (Solidity) → Junior (advanced) → Senior (security)
- **Strong Discord community** with mentors
- **Project-based**: Each level ends with a build challenge

### speed-run-ethereum
- **Built on Scaffold-ETH 2**: Full-stack template with hot-reload
- **Challenge format**: Debug contracts, build frontends, write tests
- **Active Austin builder community**

### DeFi-Developer-Road-Map
- **Best reference map**: Comprehensive topics from DeFi history to MEV
- **Reading-heavy**: Links to papers, articles, protocols
- **No hands-on exercises**

## Recommendation for Get-Started-with-Web3

| Area | Suggestion |
|------|-----------|
| **Interactive coding** | Integrate Scaffold-ETH 2 challenges as optional labs |
| **Curriculum expansion** | Add DeFi roadmap references from OffcierCia |
| **Chinese content** | Cross-reference WTF-Solidity for ZH readers |
| **Community** | Establish Discord like LearnWeb3 DAO |
| **Gamification** | Consider CryptoZombies-style interactive lessons |
